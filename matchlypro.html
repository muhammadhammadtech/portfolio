Featured Project

MatchlyPro AI Resume Matcher

A modern web application that uses AI-powered analysis to match resumes intelligently, helping users understand fit and make better career decisions.

View on GitHubView Live DemoBack to Projects

Why I Built This

I wanted to reduce the time and guesswork involved in tailoring a resume to a real job description. MatchlyPro makes the first pass of resume analysis immediate, giving applicants a clearer way to spot missing keywords and improve their chances before applying.

Key Decisions & Challenges

  • Used Gemini AI to turn resume and job-description text into useful matching and ATS insights instead of relying only on rigid keyword rules.
  • Built the interface with React and Tailwind CSS to keep the analysis flow fast, responsive, and easy to iterate on.
  • Added secure development checks and GitHub Actions before deploying the production frontend to Vercel.
